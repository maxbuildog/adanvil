# Third-party notices

AdAnvil is released under the MIT licence. This file lists the third-party components it bundles (fonts and emoji graphics), the libraries and the external program it depends on without copying them, and the demo media that is downloaded on the user's machine and never stored in this repository. The licence of each component is linked in the tables below. Licence details were checked against official sources (repository LICENSE files, licence pages, terms of service, PyPI metadata). Where a point could not be confirmed at the source, it is marked **NOT VERIFIED**. This document is not legal advice.

Legend for the column "Redistributable in a public MIT repository?": yes / no / only downloaded on the user's machine.

### 2.3 Demo media sources

Constraints: a reproducible script, ideally without a key, and respect of the terms of service. Pexels, Pixabay and Mixkit forbid scraping and bulk downloading by script; Pexels, Pixabay (videos) and Coverr offer an official API with a free key; only Wikimedia Commons allows a direct download by URL without a key (with an identified User-Agent).

Approach:

1. **Default, no key: Wikimedia Commons**, with a pinned list of a handful of CC0 or public domain files (`upload.wikimedia.org` URLs, SHA-256 verified, User-Agent `AdAnvil-demo/x.y (contact)`), each checked for its licence file by file. Limit: little product UGC-type content, so it demonstrates the editing mechanics, not commercial rendering.
2. **Quality option, with a free key: Pexels through the official API** (`PEXELS_API_KEY`, `orientation=portrait`). Commercial advertising use is allowed without mandatory attribution in the licence, but the API rules require a link to Pexels when content is displayed. No music at Pexels.
3. **Music**: no scriptable source without a validated key. Use a CC0 or public domain file from Commons, or let the user supply their own track (Pixabay or Mixkit by manual download, commercial ad use allowed, with the Content ID claim risk noted above).
4. Not used for the script: Mixkit (explicit anti-bot clause), Pixabay (clause on "mass automated downloads", no music API), Coverr (attribution mandatory through the API, "video editing services" clause to be clarified).

No media is ever committed to the repository: the script downloads into a Git-ignored folder.
